# RTL Simulations

Animated simulations of Resistor-Transistor Logic (RTL) used as a **NOR gate** and a **NAND gate**, built with [Manim Community](https://www.manim.community/). Each animation draws the circuit, steps through every input combination, shows the current as moving dots flowing either to the output or to ground, and fills in the truth table one row at a time.

## What the animations show

There are two scenes in `rtl_gates.py`:

| Scene      | Circuit                                  | Output       |
|------------|------------------------------------------|--------------|
| `NORGate`  | T1 and T2 in **parallel** below R2       | Q = NOT(A + B) |
| `NANDGate` | T1 and T2 in **series** (stacked) below R2 | Q = NOT(A . B) |

Each scene runs for about 24 seconds at 1080p60:

1. The schematic, title, and an empty truth table (`A`, `B`, `OUT`) are drawn.
2. The inputs step through `A,B = 00, 01, 10, 11`. For each step:
   - the labels `A = x`, `B = x`, `OUT = x`, and `T1/T2 ON/OFF` update,
   - a yellow box highlights the matching truth table row,
   - yellow dots flow along every conducting path at a fast, constant speed,
   - at the end of the step, that row of the truth table is written in.
3. After the last step the highlight fades out and the finished table stays on screen.

Visual style: black background, solid white drawing, bright yellow current dots. No grey is used anywhere.

## How RTL works

In RTL, the logic is built from resistors and NPN transistors. A HIGH input drives base current through the input resistor `R`, which switches the transistor ON (saturated). An ON transistor connects its collector to its emitter, so a HIGH input pulls the collector LOW. Each transistor therefore behaves like an inverter, and the way the transistors are connected decides the gate.

The current that flows from `+Vcc` through the pull-up resistor `R2` has only two possible destinations:

- **Output**: if there is no path to ground, the current goes to the output load and `OUT` is HIGH.
- **Ground**: if a path through ON transistors exists, the current sinks to ground and `OUT` is LOW.

### NOR (parallel transistors)

Both collectors connect to the output node, and both emitters connect to ground. **Either** transistor being ON is enough to pull the output LOW.

| A | B | Current from R2 flows to | OUT |
|---|---|--------------------------|-----|
| 0 | 0 | output (both transistors OFF) | 1 |
| 0 | 1 | ground through T2 | 0 |
| 1 | 0 | ground through T1 | 0 |
| 1 | 1 | ground through T1 and T2 | 0 |

### NAND (series transistors)

T1's emitter feeds T2's collector, so the only path to ground goes through **both** transistors. The output is LOW only when both are ON.

| A | B | Current from R2 flows to | OUT |
|---|---|--------------------------|-----|
| 0 | 0 | output | 1 |
| 0 | 1 | output (T1 blocks the path) | 1 |
| 1 | 0 | output (T2 blocks the path) | 1 |
| 1 | 1 | ground through T1 then T2 | 0 |

### Base current

When an input is HIGH, the animation also shows base current flowing from the input terminal, through `R`, into the base, and out of the emitter to ground. This only happens when the emitter actually has a path to ground. That is why, in the NAND scene with `A = 1, B = 0`, no dots flow from input A: T1's emitter sits on top of T2, which is OFF, so there is no complete circuit for T1's base current.

## Setup

### Requirements

| Tool | Version | Needed for |
|------|---------|------------|
| Python | 3.11 to 3.14 | Running Manim |
| pip + venv | bundled with Python | Installing dependencies |
| Cairo, Pango, pkg-config | system packages | Only on Linux (and on macOS if pip has to build from source) |
| FFmpeg | any recent build | Optional. Only needed to join the two videos into one file |

LaTeX is **not** required. All text uses Manim's `Text` class (Pango), not `MathTex`.

`requirements.txt` is pinned. macOS-only packages (`pyobjc-*`) and the Python 3.13+ backport `audioop-lts` carry environment markers, so pip skips them automatically on other platforms and older Python versions.

Start by cloning the repository on any platform:

```bash
git clone https://github.com/pizzaparth/RTL-SImulations.git
cd RTL-SImulations
```

The virtual environment is named `rtl`, which matches the entry in `.gitignore`.

### macOS

Works on both Apple Silicon and Intel Macs.

1. Install [Homebrew](https://brew.sh) if you do not already have it.
2. Install Python and the system libraries:

   ```bash
   brew install python pkg-config cairo pango ffmpeg
   ```

3. Create and activate the virtual environment, then install the dependencies:

   ```bash
   python3 -m venv rtl
   source rtl/bin/activate
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. Check the install:

   ```bash
   manim --version
   ```

### Windows

Works on Windows 10 and 11. No system libraries are needed because `pycairo` and `manimpango` ship prebuilt wheels for Windows.

1. Install Python from [python.org](https://www.python.org/downloads/windows/) and tick **Add python.exe to PATH** in the installer, or use winget:

   ```powershell
   winget install Python.Python.3.13
   ```

2. (Optional) Install FFmpeg for joining videos:

   ```powershell
   winget install Gyan.FFmpeg
   ```

3. Create and activate the virtual environment.

   PowerShell:

   ```powershell
   py -m venv rtl
   .\rtl\Scripts\Activate.ps1
   ```

   If PowerShell refuses to run the activation script, allow local scripts for your user once and try again:

   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
   ```

   Command Prompt:

   ```bat
   py -m venv rtl
   rtl\Scripts\activate.bat
   ```

4. Install the dependencies and check the install:

   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   manim --version
   ```

### Linux

```

```

Then, on any distribution:

```bash

source rtl/bin/activate

```

## Rendering the animations

Activate the virtual environment first (`source rtl/bin/activate` on macOS/Linux, `.\rtl\Scripts\Activate.ps1` on Windows), then run from the repository root.

Render both scenes at 1080p60:

```bash
manim -qh rtl_gates.py NORGate NANDGate
```

Render only one scene:

```bash
manim -qh rtl_gates.py NORGate
manim -qh rtl_gates.py NANDGate
```

Quick low-quality preview that opens when finished:

```bash
manim -pql rtl_gates.py NORGate
```

| Flag  | Resolution | FPS | Output folder |
|-------|-----------|-----|---------------|
| `-ql` | 854x480   | 15  | `480p15`  |
| `-qm` | 1280x720  | 30  | `720p30`  |
| `-qh` | 1920x1080 | 60  | `1080p60` |
| `-qp` | 2560x1440 | 60  | `1440p60` |
| `-qk` | 3840x2160 | 60  | `2160p60` |

Add `-p` to open the video when rendering finishes. Videos are written to `media/videos/rtl_gates/<quality>/`.

### Joining both videos into one

This uses FFmpeg's concat demuxer without re-encoding.

macOS / Linux:

```bash
cd media/videos/rtl_gates/1080p60
printf "file 'NORGate.mp4'\nfile 'NANDGate.mp4'\n" > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy RTL_NOR_then_NAND.mp4
rm list.txt
```

Windows (PowerShell):

```powershell
cd media\videos\rtl_gates\1080p60
Set-Content list.txt "file 'NORGate.mp4'`nfile 'NANDGate.mp4'"
ffmpeg -f concat -safe 0 -i list.txt -c copy RTL_NOR_then_NAND.mp4
Remove-Item list.txt
```

## How the code works

Everything lives in `rtl_gates.py`.

### Drawing the schematic

The circuit is built from small helper functions that return plain Manim objects in white:

| Helper | Draws |
|--------|-------|
| `poly` | A wire through a list of corner points |
| `zigzag_pts` | The corner points of a resistor zigzag between two points |
| `transistor` | An NPN symbol (circle, base bar, collector, emitter with arrow) and returns its key points: base input, bar middle, collector exit, emitter exit |
| `input_branch` | Input terminal, series resistor `R`, and base lead |
| `vcc`, `ground`, `junction`, `terminal`, `triangle` | Supply arrow, ground symbol, junction dots, input terminals, arrowheads |

All coordinates go through `P(x, y)`, which adds a global `OFFSET`. This lets the whole circuit move without editing individual points (it is shifted left to leave room for the truth table). In the NOR circuit, the T1 emitter wire crosses the collector bus without connecting, so it is drawn with a small hop.

### Current flow

Current is modelled as **segments**: named polylines along the wires, each pointing in the direction of conventional current, for example `vcc` (from +Vcc through R2 to the output node), `out`, `T1c`, `T1e`, `bus2`, `gnd`, `baseA`.

A `Flow` object places evenly spaced yellow dots along one segment. It reads a single shared clock (a `ValueTracker` advanced every frame), and each dot sits at

```
x_i = ((t * SPEED - D) mod SPACING) + i * SPACING
```

along the segment, where `D` is the segment's phase offset. Because every segment uses the same clock, speed, and spacing, dots stay evenly spaced and move at the same steady rate everywhere.

### Keeping dots continuous across junctions

Each input combination lists **chains** of segments in the order current passes through them, for example `["vcc", "bus1", "T1c", "T1e", "rail1", "gnd"]`. `make_flows` walks each chain and gives every segment an offset `D` equal to the total length of the segments before it. A dot leaving the end of one segment therefore appears at the start of the next at the same moment, so the flow looks unbroken. Base-current segments get their offset from the segment they join, so they merge smoothly at the transistor's base bar.

### Scene timeline

`RTLGate.construct` is shared by both scenes; `NORGate.build` and `NANDGate.build` only provide the drawing, segments, and input combinations.

| Time (s) | Event |
|----------|-------|
| 0.0 to 2.5 | Circuit, labels, and empty truth table are drawn |
| per step | 0.4 s label change and row highlight, 3.5 s current flow, 0.5 s row write, 0.5 s hold |
| end | Highlight fades, final 1.5 s hold |

When the inputs change, the old dots fade out while the state labels morph to their new values, then the new dots fade in over 0.2 s.

## Customisation

These constants are at the top of `rtl_gates.py`:

| Constant | Default | Effect |
|----------|---------|--------|
| `SPEED` | `3.2` | Dot speed in scene units per second |
| `SPACING` | `0.30` | Distance between dots |
| `DOT_R` | `0.075` | Dot radius |
| `DOT` | `#FFE600` | Dot and row highlight colour |
| `INK` | `#FFFFFF` | Drawing and text colour |
| `WIRE` | `4` | Wire stroke width |
| `FONT` | `Helvetica` | Font for all labels |
| `HOLD` | `4.5` | Seconds spent on each input combination |
| `OFFSET` | `[-0.4, -0.1, 0]` | Shifts the whole circuit |
| `TABLE_LEFT`, `TABLE_TOP` | `4.3`, `1.4` | Truth table position |
| `COLS`, `ROW_H` | `[0.72, 0.72, 1.1]`, `0.58` | Truth table column widths and row height |

## Troubleshooting

**`pip install` fails while building `pycairo` or `manimpango`**
The Cairo/Pango headers or a compiler are missing. Install the system packages listed for your platform above, then run `pip install -r requirements.txt` again. On Windows, this usually means no prebuilt wheel exists for your Python version; switch to a slightly older Python (for example 3.13).

**`manim: command not found`**
The virtual environment is not active. Activate it (`source rtl/bin/activate` or `.\rtl\Scripts\Activate.ps1`), or call it directly with `rtl/bin/manim` (`rtl\Scripts\manim.exe` on Windows).

**Labels use a different font**
`Helvetica` ships with macOS. On Windows and Linux, Pango falls back to the default sans-serif font, which works but looks slightly different. Set `FONT` to an installed font such as `Arial` or `DejaVu Sans` for a closer match.

**`ffmpeg: command not found` when joining videos**
Rendering does not need FFmpeg (Manim uses PyAV), but the join step does. Install it using the command for your platform above.

**Old frames show up after editing the code**
Manim caches partial clips. Render with `--disable_caching`, or delete `media/videos/rtl_gates/<quality>/partial_movie_files/`.
